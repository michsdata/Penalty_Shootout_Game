# Terminal Penalty Shootout ⚽

A fast-paced, text-based penalty shootout game built entirely in Python. Step up to the spot and test your nerves against a randomly generated computer goalkeeper in a classic best-of-five showdown.

## Game Mechanics
* **Play as Striker & Keeper:** Alternate between taking penalties and diving to make saves.
* **Cinematic Suspense (New in v2.0):** Utilises Python's `time` module to simulate the real-time tension of a penalty shootout, pausing action between the shot, the dive, and the final outcome.
* **Input Validation:** The game engine handles typos and invalid entries without crashing, ensuring smooth gameplay.
* **Randomised Computer Opponent:** The computer utilises Python's `random` module to make unpredictable shot and dive decisions.

## How to Play
1. Ensure you have Python 3 installed on your machine.
2. Clone this repository to your local machine.
3. Open your terminal, navigate to the project folder, and run:
   ```bash
   python penalty_shootout.py
